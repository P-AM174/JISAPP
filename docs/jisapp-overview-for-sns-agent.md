## 1. ジサップとは（詳細）

### 1-1. 何を解決するサービスか
AIにアプリのコードを書いてもらうことは、いまや誰でもできる。しかし「そのコードを**どこで動かし、どうやって公開するか**」で多くの人が止まる。

- サーバーを借りる／Vercel などにデプロイする／データベースを用意する／ドメインを…という壁
- 結局コードがチャットに残ったまま、誰にも使ってもらえない

ジサップは、この「AIが作ったコードのその先」を埋める。**コードをコピー → 貼り付け → 公開**の3動作で、URLが発行され、SNSで共有できる状態になる。

### 1-2. 位置づけ（正確な言い方）
- ✅ 正しい：「AIに書かせたコードをそのまま貼るだけで公開できる場所」
- ❌ 使わない：「**ノーコード**」と言い切ること。ジサップはコードを貼る仕組みであり、ノーコードツール（Bubble 等）とは別物。
- 比較するとき：「Vercelにデプロイする手間」「サーバー・DBの用意」が**省ける**、という価値で語る。他社サービスを貶めない。

### 1-3. 主な特徴（強み）
1. **サーバー設定ゼロ** — サーバー契約・環境構築が不要
2. **データベース設定不要** — 保存は `window.Zisup.saveData / loadData` だけで完結
3. **AIコードをそのまま貼る** — ChatGPT / Claude / Gemini など、HTMLを出力できるAIなら何でも可
4. **ブラウザ完結** — インストール不要。スマホだけでも作れる（通学中・移動中のチャットから数分で公開、という使い方も可能）
5. **作ったらそのまま公開** — URL発行、または公式マーケットへの掲載
6. **登録なしですぐ試せる** — 思い立った瞬間に始められる
7. **みんなのアプリを使える** — 公開アプリを検索して、その場で遊べる・使える
8. **APIキーを安全に扱える仕組み** — コードにキーを直書きせず、「シークレット管理」に登録して名前だけ指定

## 2. ターゲット（誰のためのサービスか）

公式の想定：**「プログラミング未経験の個人、学生、自分用の小さなツールを作りたい人」**

### 2-1. ペルソナ別の訴求

## 3. 何ができるか（機能一覧）

### 3-1. 作る・公開する（開発スタジオ `/playground`）
- AIが出力したHTMLを**コード欄に貼り付け**、「プレビュー更新」で右側（スマホでは下）にアプリを即表示
- 修正したいときはAIに追加で頼み、新しいコードを貼ってプレビュー更新（何度でも繰り返せる）
- 「公開/URL発行」で公開。公開方法は2つ
  - **URLのみ発行**：URLを知っている人だけがアクセスできる（限定共有）
  - **マーケットに出品**：トップページ・検索に掲載される（カテゴリ必須）。任意で**ソースコードの公開**も選べる
- **同じURLで上書き更新**できる（公開後の修正が可能）
- アプリの名前・説明・カテゴリを設定。コードサイズ上限は**512KB**、タイトルは100文字まで
- **APIキー（シークレット）管理**：外部API・AI連携用のキーを登録（後述）
- 保存方式の変更時や、コード内にAPIキーらしき文字列が埋まっているときは**警告モーダル**で知らせる

### 3-2. プロンプトを作る（チャット形式のテンプレート `/create` ・ プロンプトビルダー）
AIに送る「ジサップ専用の指示文」を、チャットの4問に答えるだけで自動生成する。

1. 作りたいアプリは何ですか？
2. 詳細・仕様・デザイン・こだわり（なければ「なし」）
3. ジサップのオリジナルデザイン（オーロラグラデーション＋すりガラス風）で作るか？
4. データの保存機能は必要か？（はい＝ログインで別端末にも残る／いいえ＝同じブラウザ内のみ）

生成された指示文には、ジサップで動かすためのルールが自動で入る（下記 §4-3）。自分で指示を書く人向けに「**必須ルールだけコピー**」も用意されている。

### 3-3. データ保存（`window.Zisup`）
アプリ側のコードからこのAPIを呼ぶだけで、DBなしにデータが残る。

| API | 役割 |
|---|---|
| `await window.Zisup.saveData('key', value)` | データを保存 |
| `await window.Zisup.loadData('key')` | 読み込み（未保存なら `null`） |
| `await window.Zisup.fetch(url, {secret:'NAME'})` | 外部API（https）へのリクエスト。CORSで直接呼べないAPI用のプロキシ経由 |

- **ログインしている**と保存先はクラウド（別の端末でも同じデータを読める）。**未ログイン**だと端末のブラウザ内に保存
- 外部APIのタイムアウト目安は約15秒

### 3-4. 外部API・AI連携とシークレット管理
- 天気API・地図・OpenAI・Gemini・Groq などと連携できる（https のみ）
- **APIキーはコードに絶対に書かない。** 「APIキー」画面で名前（大文字英数字、32文字以内。例 `WEATHER` `OPENAI` `GEMINI`）と値を登録し、コードでは `secret: 'WEATHER'` と名前だけ指定
- 付け方は「URLパラメータ型（Gemini等）」「HTTPヘッダー型（OpenAI等）」から選択
- 理由：コードに書くと閲覧者に見えてしまうため

### 3-5. マイライブラリ・マイページ・プロジェクト
- 追加した／自分が作ったアプリを一覧管理し、いつでも再実行
- ログインしてライブラリに入れたアプリのデータは端末をまたいで同期
- アプリが更新されると**アップデート通知**（更新内容つき）が届く
- 作りかけのアプリは「プロジェクト」として保存できる

### 3-6. 見つける・使う・反応する
- トップページに**人気アプリ**（月間人気ランキング）・**人気クリエイター**
- 検索ページ、**11カテゴリ**：ビジネス／生産性／生活／学習／統計／AIツール／エンタメ／趣味／スポーツ／ゲーム／その他
- アプリ詳細ページ：プレビュー、作者情報、シェアボタン、通報
- **スタンプ（4種）**：「いいね！」「天才！」「便利！」「デザインが好き！」
- **クリエイターのプロフィールページ**とフォロー機能
- 無料アプリはその場で使える

### 3-7. コミュニティ：アプリリクエスト（開発依頼掲示板 `/requests`）
「こんなツールがあったらいいな」を掲示板に投稿すると、クリエイターがアプリを作って応えてくれる。作れない人も参加できる入口。カテゴリ選択・ニックネーム任意で投稿できる。

### 3-8. 安全・運営まわり
- アプリは**サンドボックス（隔離環境）内で実行**される
- 通報機能（理由：不適切なコンテンツ／スパム・詐欺／悪意のあるコード／著作権侵害／その他）
- AIによる**コードのセキュリティ審査**の仕組みを備える（悪意あるスクリプト・フィッシング・不正なデータ送信の疑いを判定）
- 未ログインのURLのみ公開アプリは、**2か月以上アクセスがないと自動削除**される（大切なアプリはログインして保存する）
- 利用規約：有料商品のコードの不正取得・再配布は禁止

### 3-9. 収益・販売まわり（言い方に注意）
- マーケットには、作者が**有料に設定したアプリ**が並ぶ可能性がある。ただし**スタジオの利用は無料**
- 「AI安全審査・エスクロー決済」は公式サイトで**「準備中」**と表記されている段階。**決済・売上まで整った機能として断定して宣伝しない**（現状の訴求の主軸は「無料で作って公開できること」）

## 4. アプリの作り方（手順の詳細）

### 4-1. 基本の4ステップ（公式HowTo）
1. **AIに作りたいアプリを伝える** — ChatGPT・Claude・Gemini などに日本語で内容を伝え、HTMLコードを生成してもらう
2. **生成されたコードをコピーする** — 省略せず**すべて**コピー
3. **開発スタジオに貼り付けて確認する** — `jisapp.app/playground` を開き、貼り付けてプレビュー
4. **公開してURLを共有する** — 問題なければ公開し、発行されたURLを共有（サーバー契約は不要）

### 4-2. 初心者向け・8ステップ版（初心者向けの作り方ガイド）
目安時間：**2〜3時間**／必要なもの：スマホまたはパソコン、AI（ChatGPT・Gemini等）

| # | ステップ | やること | つまずいたら |
|---|---|---|---|
| 1 | テーマを決める | 毎日「面倒だな」と思うことを1つ書き、「アプリにしたら楽になる？」と考え、10文字以内のタイトルにする | 最初は「ボタン1つで記録する」など1機能から |
| 2 | ログインする | 保存・公開にはログイン（未成年は保護者と一緒に） | 試すだけならログイン不要 |
| 3 | AIへの指示文を作る | チャットの質問（作りたいもの／詳細／デザイン／保存）に答えてコピー | 詳細がなければ「なし」でOK |
| 4 | AIに送ってコードをもらう | 指示文をそのままAIに貼って送信。1〜2分かかることも | コードは**省略せず全部**コピー |
| 5 | 開発スタジオに貼り付け | コードを貼って「プレビュー更新」 | 画面が真っ白なら `<!DOCTYPE html>` で始まっているか確認 |
| 6 | 動かして、直す | 動作確認し、直したい点はAIに追加依頼して再貼り付け | 何度か直すのも大事な工程 |
| 7 | 公開してURLを得る | 「公開する」→名前・説明・カテゴリを入力 | URLはメモ帳に控える |
| 8 | レポートを書く | テーマ・目的・方法・結果・感想（テンプレあり）＋アプリURL | 提出形式は先生の指示に従う |

**テーマ例** — 低学年：九九ドリル／好きな色カウンター／今日の気分メモ　中高学年：おこづかいメモ／読書記録／勉強タイマー／オリジナルクイズ

### 4-3. ジサップで動かすためのコードのルール（AIへの指示に自動で入る内容）
- 完成コードは**1つの `index.html`**にまとめる（HTML/CSS/JSをファイル分割しない）
- **外部CDN・CSSフレームワーク（Tailwind / Bootstrap 等）は使用禁止**。デザインは生のCSSで書く
- 最初の返答で**完成した index.html を省略なしで**出す
- データを別端末でも残すなら `window.Zisup.saveData / loadData`、同じ端末だけなら `localStorage`
- **APIキーをコードに直書きしない**。外部APIは `window.Zisup.fetch(url, {secret:'NAME'})`
- ジサップ標準デザイン（任意）：エメラルド×ブルーの**オーロラグラデーション＋グラスモーフィズム**、絵文字は使わずインラインSVGアイコン、モバイルファースト（最大幅640px）

### 4-4. よくあるつまずき
| 症状 | 対処 |
|---|---|
| 画面が真っ白 | コード冒頭が `<!DOCTYPE html>` か確認／コードが途中で切れていないか確認 |
| 外部APIでエラー | CORS → `window.Zisup.fetch` に切り替え、APIキーは「APIキー」画面に登録 |
| データが消える／端末で違う | 未ログインはブラウザ内保存。ログイン→マイライブラリで同期 |
| 長いコードのコピーが大変 | スマホでも可能だが、パソコンの方が楽な場合あり |

## 5. どんなアプリが作れるか

### 5-1. 作れるもの（向いているもの）
**ブラウザの1ページで完結する、小さく実用的／遊べるアプリ。** 保存データ・外部APIも使える。

| ジャンル | 例 |
|---|---|
| **ゲーム** | 反射神経タップ／記憶カード合わせ／避けゲー／色当てチャレンジ／早押し二択クイズ |
| **診断・エンタメ** | 診断メーカー（質問→結果タイプ、結果コピー付き）／オリジナルクイズ |
| **生活** | 割り勘・即時計算／支出パッと記録（月の使用額をゲージ表示）／ペットの世話チェック／今日の気分メモ |
| **生産性** | ポモドーロタイマー／習慣トラッカー（連続日数）／カウントダウン目標ツール |
| **学習** | 九九ドリル／勉強タイマー／読書記録／暗記カード |
| **SNS・文章** | 文字数カウンター・X投稿整形（残り文字数を色で警告、ワンタップコピー） |
| **AIツール** | OpenAI・Gemini等のAPIを呼ぶチャット・要約・翻訳ツール（APIキーはシークレット管理で） |
| **統計・データ** | 記録をグラフ化するツール／集計ツール |
| **外部API連携** | 天気・地図・為替 などを表示するツール |

### 5-2. 良いアプリの条件（公式運営アプリが目指している品質）
- 最初の利用が**30秒〜2分**で何らかの「結果」に到達する
- 結果が出た瞬間に、数字が動く・色が変わるなど**分かりやすい演出**がある
- **もう一回やりたくなる**導線（やり直しが軽い）
- **自己ベスト・連続日数・累計回数**など、続けたくなる数字が保存され、次回開いた時に表示される
- 初回起動（データが空）でもエラーにならない／配色に統一感

### 5-3. 向いていないもの
- 複数ファイル構成・ビルドが必要な本格アプリ（1つのHTMLで完結しないもの）
- サーバー側の処理が必須のもの（サーバーサイドの常時稼働処理など）
- 512KBを超える規模のもの

## 6. 発信の切り口（コンテンツ設計）

### 6-1. 5W1H の視点（ジサップ紹介投稿は「1投稿＝1視点」）
| 視点 | 掘り下げどころ | 例（トーンの参考） |
|---|---|---|
| **What** | 「AIのコードを貼るだけで公開」という仕組みの意外性 | ChatGPTに作らせたコードをジサップに貼っただけで、アプリがURL付きで公開できた |
| **Who** | 初心者／学生／個人開発者など、**具体的な誰かの状況**を1つ | 「課題で出すアプリを、AIと一緒に作る」 |
| **Where** | サーバー不要・スマホだけで完結 | サーバーもDBも用意してない。スマホから5分で公開できた |
| **When** | 登録不要ですぐ／思い立った瞬間に始められる | 思いついた3分後にはURLがあった |
| **Why** | Vercelにデプロイ等と比べて手間が省ける価値 | デプロイ作業なしで、AIのコードがそのまま公開できる |
| **How** | 3ステップ（AIに作らせる→貼る→公開） | 作らせる、貼る、公開。それだけ |

**全部を1投稿に詰め込まない。** 直近の投稿と同じ視点を連続して使わない。

### 6-2. アプリ個別紹介の投稿（最重要）
- **1つの具体的なアプリ**を主役にする。ジサップ全体の説明に逃げない
- 「〇〇できるアプリ」で止めず、**「〇〇すると△△になる」まで書く**（触った瞬間が想像できる）
- 型は毎回変える：**驚き型／体験想像型／挑戦型（記録を書く）／発見型（作者を紹介）**
- URLは**そのアプリ個別のページ**（`jisapp.app/apps/{id}`）。トップページのURLで代用しない
- 良い例：「制限時間15秒で、色違いのパネルを何枚見つけられるか勝負するアプリを見つけた。最初は余裕なのに後半で急に焦る。」
- 悪い例：「新しいアプリが公開されました！ぜひチェックしてみてください！」（具体性ゼロ）

### 6-3. コンテンツピラー（週間のバランス例）
1. **アプリ紹介**（具体的な1本）— 最も反応を取りやすい柱
2. **ジサップ紹介**（5W1Hの1視点）
3. **作り方・Tips**（つまずき解消、プロンプト例、APIキーの扱い）
4. **クリエイター紹介・スタンプ多数のアプリ紹介**（人気・作者にフォーカス）
5. **季節企画**（新学期、年末の家計簿・習慣化など）。※夏休み自由研究ガイドは季節外れのため公開面から非表示中。来夏に再開するまで発信・言及しない
6. **アプリリクエスト**（「こんなの欲しい」の紹介・募集）

## 7. 発信ルール（必ず守る）

### 7-1. 表現ルール
- ブランド表記：「ジサップ（Jisapp）」。初出は併記、以降「ジサップ」でも可。**「Zisup」は開発者向けAPI名の文脈のみ**
- **「ノーコード」と言い切らない。**（「AIに書かせたコードを貼るだけ」が正確）
- 誇張禁止：「バズる」「絶対」「日本一」「必ず稼げる」など根拠のない断定は使わない
- ハッシュタグ：基本は **`#個人開発` `#ジサップ`**、内容に合えばもう1つ追加可（**最大3個**）
- 絵文字：原則控えめ。使うなら内容に合うときのみ**1〜2個まで**。3個以上は禁止、連投で同じ絵文字を使い回さない。迷ったら使わない
- 熱量のトーン：硬い広報文ではなく、**個人開発者が友達に「これ触ってみて」と勧める温度感**

### 7-2. 掲載してはいけないもの
- 実在の人物・企業・団体名、版権キャラクター・ロゴ・商標
- 誹謗中傷・差別的表現、性的・暴力的な表現、政治・宗教・特定思想への言及
- APIキー・トークンらしき文字列
- 他社サービスへの攻撃的な比較
- 実績数値（ユーザー数・アプリ数・売上）を**確認できない状態で書くこと**

### 7-3. 事実として断定してはいけないこと（現時点）
- 「決済・エスクロー・AI安全審査が稼働中」（**準備中**表記）
- 収益化・売上が出る保証
- 特定AIとの公式提携
- 未確認のユーザー数・アプリ数

## 8. 現在のSNS運用の仕組み（参考）

ジサップの公式運用は、AIエージェント＋**人の承認**で回っている。

- Claude（Haiku）が投稿下書きを生成し、**安全・品質チェックのフラグ**を付けて**承認キュー**に入れる（Slack通知あり）
- 実際のXへの投稿は**人が承認後に公式アカウントから貼る**（自動投稿はしない）
- 生成スケジュール：**月・金＝アプリ個別紹介／水＝ジサップ紹介／火・木・土＝公式運営アプリ（ゲーム・ツール）を生成**
- 公開済みアプリがなければ個別紹介の代わりにジサップ紹介を作る
- 未処理が2件たまっている間は追加生成を見送る
- 却下理由は次回の生成にフィードバックされる（同じ失敗を繰り返さない）
- 公式運営アプリは「ジサップ公式」名義のクリエイターで公開される

エージェントは、**直近投稿と似た型・視点・表現を避け**、**URLが個別アプリのページか**を必ず確認すること。
