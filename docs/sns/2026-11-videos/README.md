# SNS動画 1〜5 用のアプリ（2026年11月）

「ジサップ SNS 戦略と動画台本」（2026-11-03）の動画1〜5の撮影に使うアプリ。どれも1つの HTML で、ジサップの開発スタジオに貼ればそのまま動く。
スマホの縦画面で撮る前提で、場面やボタンが画面の大部分を使う。ゲーム系（空気読み戦線・押してはいけないボタン）は「小便器戦線」と同じ見せ方（暗い画面・黄色とピンクの太い見出し・STAGE と Q 番号・緑の進み具合・ルールのカード・黄色の START）。空気読み戦線は、電車・エレベーター・カフェなどを斜め上から見た立体風の絵で再現し、「あなた」が入口から歩いて選んだ場所に行く。効果音つき（右上のボタンで消せる）。

## 動画3 旅行代の精算（20秒）

`travel-split.html`（旅の精算ノート。ジサップのオリジナルデザインの指定どおりに作った画面）

使い方：メンバーを足す →「立て替えたものを足す」で、**何に・いくら・誰が立て替え・誰で割るか** を入れる → 全部を相殺して、誰が誰にいくら払えば終わるかが出る。

- 右上の「例を入れる」で、3人の旅行の例（名前と金額は架空）が入る
  - ホテル代 ¥15,000（あおいが立て替え）、美術館の入場料 ¥3,000（ゆうと）、夜ごはん ¥9,000（さき）、ロープウェイ ¥4,200（ゆうと）。どれも3人で割る
  - 相殺する前は8回分の支払い → **送金は2回だけ**：ゆうと→あおい ¥3,200、さき→あおい ¥1,400
- 上のチケット：のこりの送金の回数。精算のレシート：送金の一覧（払ったら右の丸を押す）と、1人ずつの「立て替え・負担・差額」
- 各費目のカードに「誰が、立て替えた人にいくらずつ払うか」が出る（相殺する前の支払い）
- 「トークに貼る文をコピー」で、費目と送金の一覧を LINE などに貼れる
- 送金の回数は、本当に最少になるように計算している（人数 − 差額が0になる組の数）。割り切れない1円は立て替えた人がかぶる
- 入力はジサップの保存機能に残る。グループで公開して開くと、立て替えと精算済みの印をメンバー全員のスマホで共有する（誰かが足すと、ほかの人の画面も更新されて「ほかのメンバーが更新しました」と出る）

台本との違い：台本の金額の例（田中→佐藤 3,240円）ではなく、上の例を使う。撮るときは、冒頭を精算のレシート（送金は2回だけ）から始め、費目のカードを足していく場面、✓ を押して「全員の精算が終わりました」で終える。

台本 13.0–16.5「最初は、この一文だけでした」で見せる AI への一文の例：

```
旅行で誰かが立て替えたもの（ホテル代・入場料・ごはん代など）を、誰が払って誰で割るか入れると、全部を相殺して、誰が誰にいくら払えば精算が終わるかを、送金の回数が一番少なくなるように出すアプリを作って
```

## 動画4 コメントの教室編をアプリへ追加（21秒）

1. 「追加する前」として `kuuki-game-before-classroom.html` を開発スタジオに貼って公開しておく
2. 台本 4.0–7.0 で AI に伝える文（下）を撮る
3. 台本 7.0–12.0「コピー → 貼る → 更新」は、`kuuki-game.html`（教室編入り）を貼り直して撮る
4. 台本 12.0–16.0 で教室問題を操作：第4問「遅刻した教室 どこに座る？」（教室編は第4問と最後の2問の計3問）

AI に伝える文の例：

```
この空気読みゲームに「教室編」を追加して。遅刻して教室に入ったときにどこに座るか、A・B・Cから選ぶ問題。
正解は後ろの空席（授業をじゃましない）、ほかは「真ん中を横切る」「一番前で目立つ」にして。今の問題とスコアはそのまま残して。
```

コメント投稿者の名前やアイコンは映さない。実在のコメントがない場合は、投票結果などを使い、そう分かるように出す（台本の編集指示どおり）。

## 動画5 押してはいけないボタン（17秒）

`dont-press.html`

| 台本 | 画面で起きること |
|---|---|
| 0.0–1.0 赤いボタンと「押さないで」 | 黄色と黒のしま模様の金属板に、赤いボタン。最初からゆれている |
| 3.0–5.0 タップ、暗転・警告音 | 1回目：画面が暗くなり「押しましたね」（強い点滅はしない・警告音は小さめ） |
| 5.0–8.0 2回目はボタンが逃げる | 2回目：小さくなって0.65秒ごとに逃げる「捕まえて」 |
| 8.0–11.0 捕まえると 3・2・1 | 捕まえる（押せる）と、デジタル表示で大きく 3・2・1 |
| 11.0–14.0 紙吹雪と「何も起きません」 | 紙吹雪と「何も起きません」「あなたは○回押しました」 |
| 14.0–17.0 最初の赤いボタンへ戻る | 2.6秒後に最初と同じ画面に戻る（ループ） |

2周目は、1回目のあとに画面が逆さまになる場面が入る（レポートのアプリ案の「画面反転」）。動画1本目は1周目で撮る。
