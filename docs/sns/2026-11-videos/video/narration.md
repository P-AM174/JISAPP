# 読み上げのセリフ表（動画1〜5）

読み上げなし版の動画（効果音だけ）に、自分で録った声を重ねるための表。
「始まり」の秒に話し始め、「使える長さ」の中で言い終える（次のセリフや場面が始まるまで）。速さの目安は 1.15〜1.25 倍の、短く区切った話し方。

## 声の差し替えのしかた

- 編集アプリで、読み上げなし版の動画に、録った声を上の「始まり」の秒に置く。
- または、セリフごとに1つのファイル（vo00.wav・vo01.wav …、上の表の順）にして渡してもらえれば、こちらで重ねて書き出す。
