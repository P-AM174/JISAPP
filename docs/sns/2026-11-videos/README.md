# SNS動画 1〜5 用のアプリ（2026年11月）

「ジサップ SNS 戦略と動画台本」（2026-11-03）の動画1〜5の撮影に使うアプリ。どれも1つの HTML で、ジサップの開発スタジオに貼ればそのまま動く。
スマホの縦画面で撮る前提で、席やボタンが画面の大部分を使う。効果音つき（右上のボタンで消せる）。

| ファイル | 使う動画 | 公開名の例 | 保存 |
|---|---|---|---|
| `kuuki-game.html` | 1・2・4 | どこに座る？空気読みゲーム | 自己ベスト |
| `kuuki-game-before-classroom.html` | 4（追加する前） | 同上 | 自己ベスト |
| `travel-split.html` | 3 | 旅行代 かんたん精算 | 入力した金額・精算済みの印 |
| `dont-press.html` | 5 | 押してはいけないボタン | 押した回数・捕まえる最速タイム |

## 動画1 電車でどこに座る（19秒）

`kuuki-game.html` → スタート → 第1問「電車 どこに座る？」

| 台本 | 画面で起きること |
|---|---|
| 0.0–0.8 座席と空席 A・B・C | 問題が出た瞬間から A・B・C が見えている（スタート画面は撮らずに、第1問の表示から使う） |
| 0.8–3.5 候補を順に光らせ 3・2・1 | 自動で A→B→C が順に光り、3秒のバーと 3・2・1 が出る |
| 3.5–6.5 B をタップ、主人公が移動 | B を押すと、主人公（🙂）が B へ動く |
| 6.5–9.5 会話に挟まれる | 「気まずい…」の吹き出しと「知らない2人の会話に挟まれる」 |
| 9.5–12.0 一番平和は A | A が緑で囲まれ「一番平和 A」 |
| 12.0–15.0 次のエレベーター問題を0.5秒 → 全20問 | 「次の問題」で第2問。全問数は `kuuki-game-before-classroom.html` なら 20問 |
| 15.0–17.5 AI→貼る→公開 | 開発スタジオで、このファイルのコードを貼って公開する画面を撮る |
| 17.5–19.0 次はどこに立つ？ | 第2問（エレベーター）の表示で終える |

動画1・2は、全20問の `kuuki-game-before-classroom.html` で撮る（台本の「全20問」と合わせる）。

## 動画2 エレベーターでどこに立つ（18秒）

第2問「どこに立つ？」。C を押す → 主人公がドアの前へ → 「降りる人の出口をブロック」→ 一番平和 B（全員と距離が均等）。
台本の「スコア画面で距離感ポイント +1」は、正解（B）を押したときの「正解！ +1」と右上の ⭐ で撮れる。

## 動画3 旅行代の精算（20秒）

`travel-split.html` →「例を入れる」→「精算する」

- 例のデータ（架空）：田中 4,760円・佐藤 13,000円・鈴木 8,000円・高橋 6,240円（合計 32,000円・1人 8,000円）
- 結果：**送金は2回だけ**。田中→佐藤 3,240円、高橋→佐藤 1,760円（金額は数字が増えていく動き）
- ✓ を2つ押すと「全員精算済み 🎉」
- 冒頭の「結果を大きく見せる」は、結果画面から撮り始める（一度精算すると、開き直しても結果画面から始まる）
- 送金の回数は、本当に最少になるように計算している（人数 − 0円になる組の数）

台本 13.0–16.5「最初は、この一文だけでした」で見せる AI への一文の例：

```
旅行のメンバーごとに立て替えた金額を入れると、誰が誰にいくら払えば精算が終わるかを、送金の回数が一番少なくなるように出すアプリを作って
```

## 動画4 コメントの教室編をアプリへ追加（21秒）

1. 「追加する前」として `kuuki-game-before-classroom.html` を開発スタジオに貼って公開しておく
2. 台本 4.0–7.0 で AI に伝える文（下）を撮る
3. 台本 7.0–12.0「コピー → 貼る → 更新」は、`kuuki-game.html`（教室編入り）を貼り直して撮る
4. 台本 12.0–16.0 で教室問題を操作：第4問「遅刻した教室 どこに座る？」（教室編は第4問と最後の2問の計3問）

AI に伝える文の例：

```
この空気読みゲームに「教室編」を追加して。遅刻して教室に入ったときにどこに座るか、A・B・Cから選ぶ問題。
正解は後ろの空席（授業をじゃましない）、ほかは「真ん中を横切る」「一番前で目立つ」にして。今の問題とスコアはそのまま残して。
```

コメント投稿者の名前やアイコンは映さない。実在のコメントがない場合は、投票結果などを使い、そう分かるように出す（台本の編集指示どおり）。

## 動画5 押してはいけないボタン（17秒）

`dont-press.html`

| 台本 | 画面で起きること |
|---|---|
| 0.0–1.0 赤いボタンと「押さないで」 | 最初からボタンがゆれている |
| 3.0–5.0 タップ、暗転・警告音 | 1回目：画面が暗くなり「押しましたね」（強い点滅はしない・警告音は小さめ） |
| 5.0–8.0 2回目はボタンが逃げる | 2回目：小さくなって0.65秒ごとに逃げる「捕まえて」 |
| 8.0–11.0 捕まえると 3・2・1 | 捕まえる（押せる）と大きく 3・2・1 |
| 11.0–14.0 紙吹雪と「何も起きません」 | 紙吹雪と「何も起きません」「あなたは○回押しました」 |
| 14.0–17.0 最初の赤いボタンへ戻る | 2.6秒後に最初と同じ画面に戻る（ループ） |

2周目は、1回目のあとに画面が逆さまになる場面が入る（レポートのアプリ案の「画面反転」）。動画1本目は1周目で撮る。
